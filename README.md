## 🚀 How to Run the Website Locally

You can run this website on your computer using any of the three simple methods below:

### Option 1: Direct File Open (Quickest — No Setup Needed)
1. Navigate to the `Portfolio1` folder on your computer (`C:\Users\kisho\Desktop\Portfolio1`).
2. Double-click `index.html`.
3. It will open directly in your default web browser (Google Chrome, Microsoft Edge, Brave, Firefox, etc.).

### Option 2: Using Python Built-in Local Server
Open PowerShell or Command Prompt in the `Portfolio1` directory and run:
```bash
python -m http.server 8000
```
Then open your web browser and go to:
[http://localhost:8000](http://localhost:8000)

### Option 3: Using VS Code Live Server Extension
1. Open the `Portfolio1` folder in Visual Studio Code.
2. If you have the **Live Server** extension installed, right-click `index.html` and select **"Open with Live Server"**.
3. The site will open automatically with live reload enabled.
